# 🎨 Portfolio: Evgeny Borovkov

Личный сайт-портфолио профессионального художника-реалиста. Представлены работы в жанрах масляной живописи и графики с возможностью фильтрации, детального просмотра и связи с автором.

🌐 **Live Demo:** (https://dimamitsart.ru/)

---

##  Особенности
- 🖼️ **Динамическое портфолио** с фильтрацией по жанрам (Портреты, Натюрморты, Пейзажи, Графика)
- 🔍 **Модальное окно (Lightbox)** для просмотра работ в полном размере с навигацией стрелками
- 🎨 **Дизайн по макету**: точное соответствие цветовой палитре (`#700000`, `#EEECe5`) и типографике из оригинального PDF
- 📱 **Полная адаптивность**: корректное отображение на десктопах, планшетах и смартфонах
- 🌀 **Анимации**: плавное появление секций при скролле (Intersection Observer), кастомный прелоадер, hover-эффекты
-  **Оптимизация**: lazy loading изображений, сжатые ассеты, GPU-ускоренные переходы
